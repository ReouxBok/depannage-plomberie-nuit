# Site vitrine — dépannage plomberie de nuit

Site statique français, responsive, sans dépendance externe. La photo de couverture est un visuel généré pour cette maquette et est incluse dans `assets/`.

## À personnaliser avant mise en ligne

1. Dans `index.html`, modifier l'objet `CONFIG` en bas de page : `brandName`, `phone` (format international recommandé) et `city`.
2. Remplacer `[VOTRE VILLE]`, décrire exactement le secteur couvert et supprimer toute prestation qui ne correspond pas à votre activité.
3. Ajouter vos vrais horaires de disponibilité, vos frais de déplacement / tarifs et modalités de devis. Ne pas publier de promesse de délai ou de disponibilité non garantie.
4. Compléter `mentions-legales.html` avec les informations exactes de l'entreprise et les informations d'hébergement requises.
5. Vérifier les obligations applicables à votre situation avant publication. Aucune donnée d'entreprise, certification, garantie ou avis client n'a été inventé.

## Déploiement GitHub Pages

Le dossier peut être poussé dans un dépôt GitHub. Activez GitHub Pages depuis la branche `main`, dossier `/ (root)` si ces fichiers sont à la racine du dépôt. Le domaine gratuit fourni par GitHub dépend du nom d'utilisateur et du dépôt.
